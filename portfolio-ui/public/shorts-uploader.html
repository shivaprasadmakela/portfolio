Shorts uploader

A personal command-line tool used only by Shiva Prasad M to upload and schedule Shorts to his own YouTube channel @shivaprasad.m. It uses YouTube API Services (YouTube Data API v3). It is not offered to the public.

  • Uploads the creator's own video with title, description, tags and a scheduled publish time
  • Sets the creator's own custom thumbnail
  • Reads back the status of the creator's own uploads
