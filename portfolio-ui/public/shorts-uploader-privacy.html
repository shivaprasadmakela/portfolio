Shorts uploader: Privacy Policy

Last updated: 12 November 2026

"Shorts uploader" is a personal command-line tool used only by Shiva Prasad M, the owner of the YouTube channel @shivaprasad.m, to upload and schedule his own YouTube Shorts. It is not offered to the public and has no other users.

What the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos and thumbnails to the owner's own channel (videos.insert, thumbnails.set) and to read back the status of those uploads (videos.list).

What is stored

Only the OAuth access/refresh token, stored on the owner's own computer with owner-only file permissions. The tool does not collect, store, sell or share any YouTube data or personal information, and it has no server or database.

Revoking access

Access can be revoked at any time at Google Account permissions. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
